# Lektoria releases

Windows downloads and automatic updates for Lektoria.

[Download the latest Windows installer](https://github.com/Connectslide121/Lektoria-releases/releases/latest)

Install Lektoria once using the Windows installer. Future versions appear as an update notification inside the app, with Download and Install and restart actions.

Existing portable users need one manual installation to enable updates. Your Lektoria data stays in the same Windows user-data folder.

This repository contains release downloads and update metadata. Application source is maintained separately.
